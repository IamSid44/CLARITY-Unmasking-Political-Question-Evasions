## 6. How much macro-F1 does the scorer leave on the table?

This is the quantity that motivates C4, and it needs **no model and no training**. Every system published on this task selects a single consensus label. The scorer rewards landing anywhere in the reference set, and — because macro-F1 weights all nine classes equally and support is endogenous — *which* member you pick matters.

| selection rule | macro-F1 | what it represents |
|---|---|---|
| majority-vote label | **0.8834** | what a perfect consensus predictor achieves |
| always the most frequent in-set class | **1.0000** | a frequency-biased model that always lands in G |
| oracle in-set choice (greedy) | **1.0000** | achievable lower bound on perfect `q` |

**Headroom = +0.1166 macro-F1** over the majority-vote rule, available to a system that picks *which* member of the reference set to name, with no change to the underlying model.

The oracle figure is a **greedy achievable lower bound**, not the true optimum (`decision.setmembership.oracle_upper_bound` prefers the currently-rarest in-set member, most-constrained items first). The true optimum is an assignment problem and is at least this large.

**Caveat on interpretation.** This is an upper bound on what a perfect `q` could reach, not a prediction of what C4 will achieve — `q` is estimated, not given. It bounds the prize, and it tells us whether the prize is worth chasing at all.
